## 残る制約・運用上の区別

- LLMへの実通信は今回の回帰テストでは実施していない。外部通信部分は模擬応答で確認した。
- LLMの変数選択は対応軸の係数絶対値順、定型説明は正の重心分離寄与順。既存の選択方法を維持し、Interpretation.mdに区別を明記した。
- シルエット探索は同じデータで探索・評価する。未知データの性能や大域的最適解は保証しない。
- 逆調整は距離・面積比に近づける計算であり、指定形状を必ず再現するものではない。
- ブラウザーの分析履歴は再読み込みで消える。必要な結果はJSONで保存する。
