# 現行アプリのパラメータ調整

この文書はWine分析画面の実装を説明します。すべての群に共通する投影軸を変更するため、特定群の重みを変えると他群にも影響します。重みを上げれば必ず分離する、という保証はありません。

## 役割と範囲

| パラメータ | 固定alphaでの作用 | 範囲 |
|---|---|---|
| `w_tg[j]` | 群jの群内共分散を強調側の行列に加える | 0〜1 |
| `w_bg[j]` | 群jの群内共分散を抑制側の行列に加える | 0〜1 |
| `w_bw[j]` | 群jと全体の重心差の行列を強調側に加える | 0〜1 |
| `alpha` | 抑制側の行列に掛ける対照強度 | 0〜20 |

`w_tg` と `w_bg` は独立です。同じ群で両方が正でもよく、和を1にする制約はありません。幾何学的効果はデータと他の重みに依存します。固定alphaの投影をLDAと同一視しません。

## 初期値

| 分析 | 対象群の `(w_tg, w_bg, w_bw)` | その他の群 |
|---|---|---|
| 全体構造 `overall` | 全群 `(0, 1, 1)` | なし |
| 1群対その他 `target` | `(1, 0, 1)` | `(0, 1, 0)` |
| 2群比較 `pair` | 対象2群とも `(1, 0, 1)` | `(0, 1, 0)` |

初期alphaは10です。画面を開いた直後はoverallの初期値を使い、探索しません。「Baroloの特徴を教えて」はBarolo対その他の分離を調べる依頼です。

## 自動探索と評価

9個の重みとalphaの計10変数を、複数の開始点から座標探索します。APIの評価回数は初期値の評価を含めて200回です。探索中の最良候補を保持します。大域的な最適解は保証しません。

投影は常に全178サンプル・元の3ラベルで学習します。全体の評価は3群それぞれの平均シルエットを等重みで集計します。1群対その他では評価ラベルだけを2群にまとめ、2群比較では対象2群のサンプルだけで評価します。対象外の群も投影の学習には参加します。

## 手動調整と逆調整

スライダーの適用では探索せず投影を再計算し、軸の向きを直前の座標に直交整合します。

ドラッグ操作では群間距離と楕円面積比の誤差をSLSQPで最小化します。重心移動は距離0.8・面積比0.2、拡大縮小は距離0.2・面積比0.8です。既定の反復上限は50です。探索中の最良候補を採用しますが、目標の完全な再現は保証しません。シルエット最大化とは別の処理です。
